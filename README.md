# FeedForge Publisher

FeedForge Publisher validates and publishes large FeedPak collections to FeedForge Hub using Google Drive, Dropbox, or Proton Drive.

[Download the latest release](https://github.com/balki97/FeedForge-Publisher/releases/latest)

- Windows, macOS, and Linux
- Add local files or complete cloud folders
- Automatic duplicate checks before submission
- Large queues processed safely in batches
- Exportable diagnostic logs and in-app update notices
